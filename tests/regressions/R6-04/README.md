# R6-04 — settle undelivered capability packets

`case.json` runs two private nodes, local MinIO and two TCP fault proxies on the fleet host. Thirty calls export fresh targets: ten requests dropped before delivery, ten failed RPC tunnel establishments and ten fully generated replies withheld from the recipient. Both process-session sockets and an unrelated live capability stay healthy. Every failed transfer must dispose its target exactly once. A delivered-and-retained argument whose reply is lost must stay callable until explicit release. Exports and heap pins must return to zero without killing either node. Proxy event counts prove each requested fault occurred. Public dummy store identities only; assigned ports plus offsets 0–9 must fit 9700–9799.

`python3 run-native.py` runs four native control-protocol tests. Three repeat 1,000 schedules each: no delivery in either direction; receipt racing sender cancellation; and receipt/release racing completion. The fourth covers cancellation during setup and transport EOF. The native fixtures seed route counts without a V8 heap; the fleet fixture verifies actual target disposal and native pins. Native protocol fixtures apply to the new implementation; the fleet is the before/after reproducer on def239b and bd65da5.

The upgraded authenticated session now carries ordered Open/Opened, Received, Finish/Settled and Release messages. A native call guard remains alive through response-body collection. The receiver atomically closes its receive slot and reports whether it received the packet. Only an authenticated negative settlement releases provisional references; an acknowledged native delivery becomes the receiver's ordinary capability owner, including unread/failed decoding cleanup. Late packets and late replies cannot adopt into a closed call. No call deadline or unauthenticated replay proof is introduced. Explicit reference release bypasses method ordering because admitted calls already own independent references; a failed ordered call cannot block teardown. Peer protocol is 8; mixed versions are rejected.

Celld retains HTTP payload transport and carries its ownership settlement on the authenticated connection; this is an adapter, not a claim of Cap'n Proto protocol equivalence.
