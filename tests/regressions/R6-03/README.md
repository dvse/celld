# R6-03 — RPC streams are session capabilities

Three private processes and local MinIO test readable/writable RPC arguments/results, mixed graphs, Request/Response bodies, EOF, close, cancellation and abort. A third process forwards streams; killing holders must cancel the source once and return native exports/pins to zero. Run case.json on the fleet host. Same-isolate oracle control: CELLD_TEST_RUNTIME=workerd and the standard ../http_case.py runner use the same program's root endpoint and expected.json.

`node decode.mjs` exercises the actual packet collector and decoder: all three marker kinds are included exactly once, a successful partial import is disposed once after a later decode error, and the unclaimed wire reference is canceled once. Native packet ownership keeps unclaimed references until successful completion. Forwarded stream moves reserve a reference before encoding and commit only after the whole graph serializes.
